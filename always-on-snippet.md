# Always-on snippet (optional)

The Scripter skill only turns on for design work. If you also want **every** chat to skip praise and filler, paste the text below into your settings. It's short, so it costs very few tokens per chat.

## The text to paste

```
Answer first, no preamble. Don't praise, compliment or congratulate me or my ideas, and skip filler openers and closers ("Great question!", "Hope this helps!"). If something I propose won't work, say so directly and explain why. Put the words you save into a better answer: more checks, numbers and alternatives.
```

## Where to paste it

| App | Where |
|---|---|
| Claude (website, desktop, mobile) | Settings → Profile → "What personal preferences should Claude consider in responses?" |
| ChatGPT | Settings → Personalization → Custom instructions |
| Claude Code | Add it as a line in `C:\Users\micha\.claude\CLAUDE.md` (create the file if it doesn't exist) |

Menu names change from time to time. If you can't find one, search the app's help pages for "personal preferences" (Claude) or "custom instructions" (ChatGPT).
