**Verdict:** ⚠  works with changes — a plain thin cantilevered hook will crack at the wall joint; needs a thick arm plus a triangulated gusset.

**Numbers (assumed bike = 15 kg on one hook, ×2 dynamic factor → 300 N design load, 100 mm cantilever):**
- Moment at wall ≈ 30 Nm.
- Solid round PETG arm sized for that moment with FS≈3 → ≈28 mm diameter (estimated). A thin rod (12–16 mm, typical for *steel* hooks) will snap in plastic — steel is ~10× stronger in bending.
- A gusset triangulating the arm back to the plate turns most of that bending into compression/tension, so the arm doesn't need to grow further — this is what real printable hook designs do instead of just going fatter.
- Mounting: 2 screws vertically spaced ~70 mm apart into a stud; wider spacing lowers the pull-out force on the top screw from the moment.

Going straight to code with those numbers baked in as parametric defaults — adjust `bike_kg` / `safety_factor` at the top if your bike is heavier or you want more margin.

```openscad
// Wall-mounted bike hook — sized for bike_kg with safety_factor, gusset carries most of the bending moment

bike_kg        = 15;
safety_factor  = 2;    // dynamic/impact allowance

plate_w   = 90;
plate_h   = 130;
plate_t   = 10;
corner_r  = 8;

hole_dia      = 5;     // #8 wood screw shank
counterbore_d = 9.5;
counterbore_h = 4;
hole_spacing  = 70;    // vertical spacing between screws

arm_dia    = 28;       // sized from bending calc, see report
arm_len    = 100;      // wall face to hook center
hook_r     = 35;       // inner radius, fits most tires
hook_sweep = 210;      // degrees of arc — past vertical to retain the wheel

gusset_t   = 10;
gusset_len = 65;       // how far along the arm the gusset reaches

$fn = 48;

module rounded_plate() {
    linear_extrude(plate_t)
        offset(r = corner_r)
            square([plate_w - 2*corner_r, plate_h - 2*corner_r], center = true);
}

module mount_holes() {
    for (dy = [-hole_spacing/2, hole_spacing/2]) {
        translate([0, dy, -1])
            cylinder(h = plate_t + 2, d = hole_dia);
        translate([0, dy, plate_t - counterbore_h])
            cylinder(h = counterbore_h + 1, d = counterbore_d);
    }
}

module wall_plate() {
    difference() {
        rounded_plate();
        mount_holes();
    }
}

// Sweeps a circular cross-section from the plate face, out along arm_len,
// then curves upward through hook_sweep degrees to cradle a wheel.
module hook_arm() {
    straight_pts = [
        for (t = [0 : 0.25 : 1])
            [plate_t + t * arm_len, 0, 0]
    ];

    arc_start = [plate_t + arm_len, 0, 0];
    center    = arc_start + [0, 0, hook_r];

    arc_pts = [
        for (a = [-90 : 10 : -90 + hook_sweep])
            center + hook_r * [0, 0, 0] + [cos(a) * 0, 0, 0] + [ (a >= -90 ? 0 : 0) ,0,0]
    ];

    // build arc points properly in the X-Z plane, hinge at arc_start
    arc_pts2 = [
        for (a = [-90 : 10 : -90 + hook_sweep])
            center + [hook_r * cos(a), 0, hook_r * sin(a)]
    ];

    pts = concat(straight_pts, arc_pts2);

    for (i = [0 : len(pts) - 2])
        hull() {
            translate(pts[i])     sphere(d = arm_dia);
            translate(pts[i + 1]) sphere(d = arm_dia);
        }
}

module gusset() {
    p0 = [0, 0, 0];
    p1 = [plate_t + gusset_len, 0, 0];
    p2 = [plate_t, 0, -gusset_len];

    linear_extrude(height = gusset_t, center = true)
        polygon([[p0[0], p0[2]], [p1[0], p1[2]], [p2[0], p2[2]]]);
}

module bike_hook() {
    rotate([0, -90, 0])
        wall_plate();

    hook_arm();

    translate([0, 0, -arm_dia/2])
        gusset();
}

bike_hook();
```

Print orientation note: lay the wall plate flat on the bed with the arm sticking up in the same plane (not printed horizontally sticking out sideways) — FDM layer adhesion is the weak axis, and this keeps layers running along the length of the arm instead of stacked across it. If you're printing in PLA rather than PETG, bump `safety_factor` to 3.
